# Query the Event Log

Open **Context → Event Log** from the desktop bottom bar. Choose a log instance that contains events for the workflow you're investigating. Histories and logs are only useful for the activity they recorded.

1. Click **Filters** and enter an **Event type** or **Stream ID**, and click **Apply**.
2. Expand an event to inspect its payload and metadata.
3. Compare the selected events by timestamp to understand the sequence of recorded activity.

For programmatic queries, see [Persistence and Event Log](../../04_build-on-codebolt/07b_subsystems/12_persistence-and-eventlog.md).
