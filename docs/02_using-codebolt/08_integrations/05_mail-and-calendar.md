# Mail and Calendar

Mail and Calendar are built into Codebolt Desktop and store their data in the open project.

## Mail

Open **Tools → Inbox** to read and manage messages from agents. For project mail threads and agent coordination, see [Inbox & Agent Mail](../07c_agent-coordination/03_mail-inbox.md).

## Calendar

Open **Tools → Calendar** to add project events and view scheduled automations configured to appear there. [Calendar & Scheduled Events](../08d_auto-interactivity/03_calendar-events.md)
