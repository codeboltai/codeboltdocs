# Orchestrators

In CodeBolt, orchestration is a pattern in which a parent agent divides work among subagents and combines their results. Start with a parent agent in chat and use [subagent delegation](../../04_build-on-codebolt/03_agent-extensions/08_subagents.md) to run related work.

## Follow delegated work

Open **Execution → Thread Coordination** from the desktop bottom bar. The panel shows related threads and executions so you can see where work was delegated, open a thread, and stop an execution.

Use [Jobs & Job Groups](./02_jobs.md) to track shared work items and [Swarm Management](./05_swarm-management.md) to manage a swarm.
