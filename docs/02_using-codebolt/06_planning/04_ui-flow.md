# UI Flow

Use **Plan → Canvas** to sketch screens and transitions. Keep related written requirements in a [Note](./03_specs.md), then add a **Canvas Link** to a [Feature Plan](./01_overview.md#feature-plans).

For example, sketch the sign-in screen, the reset request, and the confirmation state on one canvas, then add it to the plan for the sign-in work.
