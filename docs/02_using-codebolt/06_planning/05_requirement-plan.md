# Requirement Plan

Use **Plan → Feature Plan** to collect the materials for a feature. Select **Create New Plan**, name the feature, and add Markdown or code sections. Use **Note Link** for written requirements, **Canvas Link** for visual context, and **Execution Plan Link** for the implementation steps.

For example, a sign-in feature plan can link a requirements note, a canvas showing the reset flow, and an execution plan for the implementation and tests.
