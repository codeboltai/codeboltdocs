# Application Features Overview

Codebolt Desktop brings your code editor, terminal, Git tools, planning panels, and agent conversations into the same project workspace. Use the top bar for project navigation and settings, and use the bottom bar to open panels as you need them.

## Find what you need

| What you want to do | Where to look |
|---|---|
| Open a folder, switch workspaces, or create a project from a template | [Workspace and Project Management](./02_surfaces/02_desktop-app/01_workspace-and-project-management/01_overview.md) |
| Open panels or change the workspace layout | [Application Navigation](./02_surfaces/02_desktop-app/02_application-navigation/00_overview.md) |
| Ask an agent about your code, attach a file, or return to an earlier conversation | [Chat](./02_surfaces/02_desktop-app/03_chat/01_overview.md) |
| Edit a file, run tests in the terminal, review a Git diff, or preview your app | [Code and Terminal](./02_surfaces/02_desktop-app/03b_code-and-terminal/01_overview.md) |
| Capture a requirement, sketch an interface, or track a task | [Planning](./06_planning/01_overview.md) |
| Choose models, configure tools and providers, or change the theme | [Settings](./02_surfaces/02_desktop-app/Settings/01_overview.md) |

## Get started

If you’re setting up Codebolt for the first time, follow the [Installation guide](../01_get-started/installation.md). With a project open, use the [Quickstart](../01_get-started/03_quickstart.md#run-your-first-agent) to ask your first question about the codebase.

For terminal and browser workflows, see the [Platform Overview](./02_surfaces/01_overview.md). To browse features across Codebolt, see the [Features overview](./01_features-overview.md).
