# Chat Canvas

**Chat Canvas** displays project threads on a two-dimensional surface. Open it from the **Execution** panel group or search for **Chat Canvas** in the desktop panel selector.

- Select **New Chat** to create a thread and expand it on the canvas.
- Select a node to expand or collapse that conversation. Several conversations can stay open at once.
- Drag nodes to arrange the view. Use **Auto Layout** to arrange them by parent-child relationships and **Refresh** to reload threads.

Edges between parent and child threads come from their existing relationship. Connections you draw are visual annotations for the current view. The app keeps node positions and expanded nodes in local UI storage.
