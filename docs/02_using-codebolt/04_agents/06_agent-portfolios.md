# Agent Portfolios

An agent portfolio is the profile record for an individual agent. Open **Agents**, find the agent in the installed list, and select **View Details** to open **Agent Profile**.

![Agent Portfolio](/productImages/agents/agent_portfolio.png)

## Viewing your portfolio

The **Overview** tab shows the agent's profile and available totals. Use the other tabs to inspect **Conversations**, **Testimonials**, **Karma**, **Appreciations**, and **Talents**. The displayed data depends on what has been recorded for that agent.

The [Agent Portfolio API](../../05_reference/02_codeboltjs/10_api-access/agentPortfolio/index.md) can read profile data and record feedback such as testimonials, karma, and talent endorsements.

## Pinned agents

Use the pin control in the chat agent selector to keep that agent selected for new input in the current app session.
