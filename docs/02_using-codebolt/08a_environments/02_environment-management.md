# Environment Management

Open **Environment** from the desktop panel selector. Create an environment to run work with a specific runtime provider, or select an existing environment to see its status and details.

Use **Refresh environments** to reload the list from connected providers. Enable **Show stopped environments** if you need to find an environment that is no longer running. Use the environment's menu to open it in a panel, stop an active environment, or review the **Close and clean up…** action.

See [Configuring Environments](./02_configuring-environments.md) for provider and creation options.
