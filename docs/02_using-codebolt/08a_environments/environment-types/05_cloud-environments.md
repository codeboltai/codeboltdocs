# Cloud Environments

Use a cloud environment when you want an agent to work in a project on a remote runtime. You can reuse a connected runtime or create one for the task.

1. Open **Remote Chat** in the cloud portal and choose a project.
2. In the environment selector, choose an existing runtime to continue working there. To start a fresh environment, choose a configured sandbox provider or a connected runner node.
3. For a new environment, review the project path and the sync options offered by the provider. If using Git, check the repository and branch before starting work.
4. Select an agent and send the task. Inspect the results in the selected environment. For work synced through Git, check the destination branch before merging.

See [Cloud environment setup](../../02_surfaces/06_cloud/04_running-agents/02_environments.md) for provider options and [Runner Nodes](../../02_surfaces/06_cloud/04_running-agents/05_runner-nodes.md) to connect your own machine.
