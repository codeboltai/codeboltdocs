# Runner Hosted Environments

A runner-hosted environment runs on a machine connected to Codebolt as a runner node. Start and connect the runner first, then select it as the provider when creating an environment. Keep the runner connected while the environment is in use.

See [Runner Nodes](../../02_surfaces/06_cloud/04_running-agents/05_runner-nodes.md) for connection instructions and [Environment Management](../02_environment-management.md) for desktop controls.
