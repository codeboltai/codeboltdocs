# AI Models

The Registry’s **AI Models** page (`/aiModels`) displays a **CodeLoom Model** row. Its **Open** switch changes the displayed state only.

To configure a provider or choose the default model for a cloud agent, open [LLM Provider Settings](../05_settings/05_llm-provider-settings.md). To start a conversation with a cloud agent, see [Remote Chat](../04_running-agents/01_remote-chat.md).
