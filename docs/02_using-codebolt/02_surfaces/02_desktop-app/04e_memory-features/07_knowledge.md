# Knowledge

Knowledge stores source documents and collections that agents can retrieve from. Use it for project material that should be searchable and reusable across prompts.

Open via: **Context menu -> Knowledge**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Create and manage knowledge collections.
- Add documents or URL-based sources.
- Inspect chunking and collection settings.
- Rechunk or remove stale documents.
