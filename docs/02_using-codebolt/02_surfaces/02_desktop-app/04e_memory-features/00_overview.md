# Memory

Memory covers the desktop panels used to store task memory, project knowledge, retrieval indexes, and long-running context infrastructure.

Open these panels from the **Context** bottom-bar menu, the panel-header **+** menu, or the Panel Selector.

## Feature map

| Feature | Use it for |
|---|---|
| [Memory](./01_memory.md) | Manage todo, markdown, JSON, and episodic memory threads used by agent work. |
| [Persistent Memory](./02_persistent-memory.md) | Define reusable memory types and retrieval pipelines for project context. |
| [Memory Ingestion](./03_memory-ingestion.md) | Ingest files, events, and records into memory pipelines. |
| [Context Assembly](./04_context-assembly.md) | Inspect how context is retrieved and assembled before an agent run. |
| [Context Compaction](./05_context-compaction.md) | Configure and inspect workflow-driven compaction for long threads. |
| [Vector DB](./06_vector-db.md) | Inspect vector-backed retrieval data. |
| [Knowledge](./07_knowledge.md) | Manage knowledge collections and source documents. |
| [Knowledge Graph](./08_knowledge-graph.md) | Explore graph entities, records, and relationships. |
| [KV Store](./09_kv-store.md) | Manage key-value storage used by project and agent workflows. |

## Related features

Deposition handoff surfaces such as Event Log, Artifacts, Inbox, Calendar, and Changes Summary are documented in [Deposition Framework Features](../04c_deposition-framework-features/00_overview.md).
