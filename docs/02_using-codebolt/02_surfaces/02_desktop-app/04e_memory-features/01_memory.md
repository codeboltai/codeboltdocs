# Memory

The Memory panel stores reusable project context and task memory. It is also used by planning features such as Action Plans when todo-style memory threads are attached to work.

Open via: **Context menu -> Memory**, the panel-header **+** menu, Panel Selector, or memory result widgets in chat.

## What you can do

- Create and inspect memory threads.
- Work with todo, markdown, JSON, and episodic memory records.
- Open memory from chat templates or planning panels.
- Archive memory that should no longer appear in active workflows.
