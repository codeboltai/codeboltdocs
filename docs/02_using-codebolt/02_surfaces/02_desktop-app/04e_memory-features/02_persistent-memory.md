# Persistent Memory

Persistent Memory stores durable memory definitions and retrieval pipelines. Use it when project knowledge needs to survive across sessions and be retrieved consistently during agent work.

Open via: **Context menu -> Persistent Memory**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Create and manage persistent memory types.
- Configure retrieval and ingestion behavior.
- Validate memory definitions before using them in agent workflows.
- Execute or inspect memory pipelines.
