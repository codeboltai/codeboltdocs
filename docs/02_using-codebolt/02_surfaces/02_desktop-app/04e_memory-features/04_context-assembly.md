# Context Assembly

Context Assembly shows how Codebolt collects memory, rules, retrieval results, and other context before an agent run. Use it when an agent seems to be missing information or receiving too much irrelevant context.

Open via: **Context menu -> Context Assembly**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Inspect memory types available to context assembly.
- Evaluate context rules before running an agent.
- Review matched memories and retrieval results.
- Debug why specific context was included or excluded.
