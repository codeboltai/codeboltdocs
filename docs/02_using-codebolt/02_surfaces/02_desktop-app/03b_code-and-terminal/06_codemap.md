# Codemap

Use a Codemap to understand a specific code path. It can contain an explanation, a diagram, and traces that link to source locations.

## Generate a codemap

1. Open **System → Settings → Code Editor Setting** and select a **Codemap Agent**.
2. Open **Debug → Codemap** and describe the flow you want to map. For example, ask how a request reaches the project settings screen.
3. Select **Generate** and open the resulting entry in **Codemaps**.

## Navigate from a trace to code

Expand a trace and select a linked source location to open it in the editor. Select **Show Diagram** if the map includes a diagram.

For recorded operations from an agent run, use [Narrative Graph](./07_narrative-graph.md).
