# MCP Servers

![MCP Servers in Customize with the Installed list and search field](/img/desktop/mcp-servers.webp)

Open **Agents → MCP** from the desktop bottom bar to manage installed servers.

## Installed tab

Search for a server by name. Use **Configure** to edit its settings, or use the switch beside it to enable or disable access. Enabling a disabled server opens the settings dialog so you can supply its configuration.

## Find new servers

Open **System → Marketplace**, select **MCP**, and choose the server you want to install. Follow [MCP Servers](../../../04b_agent-extensions/06_mcp-server.md) for installation and tool selection in Chat.
