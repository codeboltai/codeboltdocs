# Settings

The Settings panel is the central place to configure Codebolt — LLM providers, agent behaviour, environment tools, language servers, MCP servers, appearance, and more.

Open via: **Top navbar → Settings button** or **Bottom bar → System → Settings**

## Settings sections

| Section | Purpose |
|---|---|
| [Default Settings](./02_llm-settings.md#default-settings) | Choose the default LLM and embedding model for the application |
| [LLMs](./02_llm-settings.md#llm-providers) | Add and manage LLM provider API keys; browse available models |
| [Agent LLM roles](./03_agent-settings.md#agent-llm-settings) | Assign models from the individual agent's profile |
| [Universal Agent](./03_agent-settings.md#universal-agent) | Set the custom endpoint URL and offline preference |
| [Agent Steps](./03_agent-settings.md#agent-steps) | Save agent selections for named development steps |
| [Code Editor Setting](./03_agent-settings.md#code-editor-setting) | Choose agents for Cmd+K inline editing and codemap generation |
| [Environment & Services](./04_environment-services.md#environment--services) | Verify installed runtimes and manage external service API keys |
| [Environment Provider](./04_environment-services.md#environment-provider) | Add and configure Docker, E2B, local, and remote execution providers |
| [Merge Config](./04_environment-services.md#merge-config) | Set strategy for merging environment changes back into the project |
| [Language Servers](./05_language-servers.md) | Install and configure LSP servers for code intelligence |
| [MCP Servers](./06_mcp-servers.md) | Manage installed servers from **Agents → MCP** and find new ones in **System → Marketplace** |
| [Pheromones](./07_appearance.md#pheromones) | Define custom pheromone types for stigmergic agent coordination |
| [Appearance](./07_appearance.md#appearance) | Customise the application visual theme |
| [Themes](./08_themes.md) | Switch built-in themes, create custom themes, and import or export theme JSON |
| [Global Settings](./07_appearance.md#global-settings) | CLI setup and editor background colour |
