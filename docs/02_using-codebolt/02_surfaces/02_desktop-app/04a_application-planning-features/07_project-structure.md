# Project Structure

The **Project Structure** panel shows the modeled structure of the application. Use it when planning packages, routes, data stores, APIs, interfaces, deployment settings, and application layers.

Open via: **Settings menu -> Project Structure** or the Panel Selector.

## What you can do

- Inspect package-level metadata.
- Review API routes, UI routes, data stores, interfaces, and application layers.
- Understand the current structure before writing specs or action plans.
- Use project-structure context before creating an Update Project Structure Request.
