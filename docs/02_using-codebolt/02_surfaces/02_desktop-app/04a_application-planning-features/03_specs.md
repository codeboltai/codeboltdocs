# Specs

The **Specs** panel opens `.specs` files in a structured editor. Use it to document the requirement, acceptance criteria, implementation notes, and review context for a feature.

Open via: **Plan menu -> Specs**, by opening a `.specs` file from the file tree, or from planning widgets in chat.

## What you can do

- Create and open specs files.
- Edit structured requirement sections.
- Add comments when reviewing spec content.
- Keep specs beside UI flows and action plans in the same workspace layout.
- Link specs into a Requirement Plan for larger planning packages.
