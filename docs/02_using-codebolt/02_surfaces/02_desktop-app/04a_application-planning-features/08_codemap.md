# Codemap

The **Codemap** panel opens `.codemap` files that describe code paths, traces, and file references. Use it when planning changes against existing code and when agents need a map of relevant implementation areas.

Open via: opening a `.codemap` file from the file tree, **Debug menu -> Codemap**, or the Panel Selector.

## What you can do

- Open generated codemap files.
- Inspect trace names, locations, and related files.
- Use codemap context while creating specs, action plans, or requirement plans.
- Pair codemaps with Changes Summary and Review Merge Requests when planning follow-up work.
