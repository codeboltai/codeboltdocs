# Application Navigation

Application Navigation covers how you move around the Codebolt desktop app: using the top header, bottom footer, panel menus, panel tabs, and saved layouts.

## Top header

The top header gives you project-level navigation and global commands.

| Header area | Use it for |
|---|---|
| **Left** | Return to Projects, toggle left/right/bottom edge sidebars, and switch or save layouts. |
| **Center** | See the current project name, reveal the project in the file manager, or identify the running app mode. |
| **Right** | Open Settings, Project Settings, Go to File, Command Palette, New Panel Selection, Help, user/account controls, update status, and OS window controls where applicable. |

## Bottom footer

The bottom footer is the main launcher for working surfaces and app-level status.

| Footer area | Use it for |
|---|---|
| **Left** | Open Git, Code, Chat, Terminal, Agents, Plan, Tools, Execution, Debug, Context, and System menus. |
| **Right** | Review notifications and open Support actions such as issue reporting or feedback. |

## Panel management

Panels are the main working surfaces in Codebolt. You can open them from the footer groups, the panel-header **+** menu, the top header panel picker, or the in-workspace Panel Selector.

## Layout management

The desktop workspace is a Dockview layout. Panels can be stacked as tabs, split side by side, placed above or below each other, resized, and saved as named layouts.
