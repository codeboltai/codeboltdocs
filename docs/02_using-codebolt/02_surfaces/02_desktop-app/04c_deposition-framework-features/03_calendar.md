# Calendar

The **Calendar** panel stores scheduled events, reminders, and recurring triggers. In deposition workflows, a calendar event can hand work to a future time, user, or agent.

Open via: **Tools menu -> Calendar** or the Panel Selector.

## What gets deposited

- One-time scheduled events.
- Recurring events.
- Event descriptions and participants.
- Agent-triggering schedule metadata.
- Time-based pickup instructions.

## Calendar views

The desktop calendar includes month, week, day, hour, and schedule-style views.
