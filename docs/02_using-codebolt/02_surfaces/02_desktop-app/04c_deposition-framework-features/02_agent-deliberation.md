# Agent Deliberation

The **Agent Deliberation** panel records structured multi-agent decisions. Use it when several agents should respond to a question, compare answers, vote, and leave behind a summary or winner.

Open via: **Execution menu -> Agent Deliberation** or the Panel Selector.

## What gets deposited

- Deliberation request and title.
- Participating agents and users.
- Agent and user responses.
- Votes and selected winners.
- Summaries and summary authors.
- Completion or closed status.

## Pickup workflow

1. Open the deliberation.
2. Review responses, votes, and summary.
3. Use the selected winner or summary as the decision record.
4. Link the deliberation ID from follow-up work when another agent needs the decision context.
