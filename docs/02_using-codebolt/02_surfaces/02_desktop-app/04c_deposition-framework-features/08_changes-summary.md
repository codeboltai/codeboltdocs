# Changes Summary

The **Changes Summary** panel opens structured change-summary files generated by agent workflows. It is usually supporting evidence for review and merge workflows rather than a standalone queue.

Open from file-tree entries, editor actions, Review Merge Request links, or any workflow that stores a changes summary path.

## What gets deposited

- Summary of changed files.
- Explanations of why changes were made.
- Risks, issues faced, or remaining tasks when included by the producing agent.
- File-level evidence that reviewers can inspect before approving or merging work.

## Pickup workflow

1. Open the changes summary linked from the review or file tree.
2. Check the changed files and explanation.
3. Compare the summary with linked artifacts, jobs, or review feedback.
4. Use it as supporting evidence for approval, rejection, or follow-up work.
