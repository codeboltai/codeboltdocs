# Review Merge Requests

The **Review Merge Request** panel is a deposition surface for agent-generated changes that need review, feedback, approval, or follow-up work.

Open via: **Execution menu -> Review Merge Request** or from agent-generated review widgets.

## What gets deposited

- Proposed change summary.
- Linked artifacts.
- Linked jobs.
- Proposed follow-up jobs.
- Review feedback.
- Approval or merge decision.

## Pickup workflow

1. Open the review request.
2. Inspect the linked artifacts, jobs, and feedback.
3. Approve, reject, or create follow-up work.
4. Use the review request as the durable handoff record for the next agent or user.
