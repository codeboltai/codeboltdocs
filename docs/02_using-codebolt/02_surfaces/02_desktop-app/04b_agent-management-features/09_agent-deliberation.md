# Agent Deliberation

The **Agent Deliberation** panel records structured multi-agent decisions. Use it when several agents should respond to a question, compare answers, and produce a summary or winner.

Open via: **Execution menu -> Agent Deliberation** or the Panel Selector.

## What you can do

- Create a deliberation request.
- Review responses from participating agents.
- View summaries and selected winners.
- Spawn agents from the deliberation workflow when available.
- Reuse deliberation IDs as durable evidence in later workflows.
