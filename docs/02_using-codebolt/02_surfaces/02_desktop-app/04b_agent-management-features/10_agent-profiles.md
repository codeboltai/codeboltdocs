# Agent Profiles

The **Agent Profile** panel shows profile-level context for an agent. It is opened from agent-related surfaces when you need more detail about the selected agent.

## What you can inspect

- Agent overview and identity.
- Conversation history.
- Talent and capability sections.
- Karma, appreciation, and testimonial sections.
