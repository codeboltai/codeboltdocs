# Orchestrator Management

The **Orchestrator Management** panel is used when one coordinating layer assigns and tracks work across other agents.

Open via: **Execution menu -> Orchestrator Management** or the Panel Selector.

## What you can do

- View orchestrator detail.
- Review agents connected to an orchestrator.
- Use the combined chat view for orchestration context.
- Configure orchestrator settings.
- Monitor orchestrator events through the orchestrator socket.
