# Eval

Eval is the desktop surface for evaluating agent behavior. Use it when you need to compare outputs, inspect evaluation runs, and track whether an agent workflow behaves consistently.

Open via: **Agents menu -> Eval**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Review evaluation runs and results.
- Use evaluations to compare prompt, tool, or workflow behavior.
- Track quality changes after updating agents, capabilities, or action blocks.
- Pair evaluation results with Guardrails when deciding whether a workflow is safe to automate.
