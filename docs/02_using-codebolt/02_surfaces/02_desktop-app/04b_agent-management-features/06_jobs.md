# Jobs

The **Jobs** panel is the desktop work queue for coordinated agent work. Jobs can be created by users, agents, swarms, or orchestrators.

Open via: **Tools menu -> Jobs** or the Panel Selector.

## What you can do

- Create jobs and job groups.
- Open job detail panels.
- View jobs as lists, timelines, or heatmaps.
- Track status, ownership, labels, and grouped work.
- Use swarm-created job groups such as `SWARM-{name}`.
