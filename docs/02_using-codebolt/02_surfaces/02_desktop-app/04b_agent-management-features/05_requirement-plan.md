# Requirement Plan

The **Requirement Plan** panel creates an aggregation document for a feature or workflow. It can pull together specs, UI flows, action plans, previews, and Markdown sections.

Open via: **Plan menu -> Requirement Plan** or the Panel Selector.

## What you can do

- Create a new requirement plan.
- Select existing specs, UI flows, and action plans.
- Preview linked planning artifacts inline.
- Use one plan as the context package for an agent or future session.
