# Action Block

Action Blocks are reusable executable units. Agents, hooks, event actions, and automations can use them to run structured behavior instead of repeating the same tool sequence manually.

Open via: **Agents menu -> Action Block**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Browse available action blocks.
- Inspect action block metadata and source.
- Use action blocks as reusable building blocks for agent execution.
- Pair action blocks with Hooks and Event Actions for event-driven automation.
