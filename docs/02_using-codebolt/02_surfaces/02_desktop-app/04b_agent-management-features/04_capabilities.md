# Capabilities

Capabilities are reusable agent abilities that can be selected from the chat input, attached to work, or managed from the Agents menu.

Open via: **Agents menu -> Capabilities**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Browse available capabilities.
- Search for a capability before attaching it to a prompt.
- Inspect capability metadata and availability.
- Use capabilities to narrow what an agent should be allowed or expected to do.
