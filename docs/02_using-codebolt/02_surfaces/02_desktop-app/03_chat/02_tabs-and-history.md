# Tabs and History

Use Chat tabs to switch between conversation threads. Each thread has its own message history.

## Tabs

Select **New Chat** in the Chat header to create a thread. Use the tab strip or the open-threads menu to switch between threads and see which ones are running. Closing a tab removes it from the panel. You can open the conversation again from **History**.

Independent threads let you work on several requests at once. Threads in the same project may still change the same files.

## History

Open **History** in the Chat header and use **Search conversations** to find an earlier thread. Select the conversation to reopen it.
