# Agent Orchestrations

Agent Orchestrations covers the desktop panels that decide where agent work runs, how requests are routed, and how execution is proxied through local or remote runtimes.

Open these panels from the bottom bar menus, the panel-header **+** menu, the Panel Selector, or the System menu where available.

## Feature map

| Feature | Use it for |
|---|---|
| [Proxy Execution](./01_proxy-execution.md) | Configure and inspect proxy-backed execution paths used by agents and tools. |
| [Routing Gateway](./02_routing-gateway.md) | Route messages from chat, plugins, webhooks, and external channels to the correct agent or response target. |
| [Environments](./03_environments.md) | Manage local, cloud, runner, and child execution contexts used by agent runs. |
