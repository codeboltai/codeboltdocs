# UI Flow

The **UI Flow** panel opens `.canvas` files that describe screens, states, and workflow transitions. Use it when the plan needs visual context in addition to written specs.

Open via: **Plan menu -> Ui Flow**, by opening a `.canvas` file from the file tree, or from a linked Requirement Plan.

## What you can do

- Open UI flow canvas files.
- Inspect screens, transitions, and workflow context.
- Keep UI flows beside specs and action plans while refining implementation.
- Link UI flows into a Requirement Plan so agents can load the design context with the written plan.
