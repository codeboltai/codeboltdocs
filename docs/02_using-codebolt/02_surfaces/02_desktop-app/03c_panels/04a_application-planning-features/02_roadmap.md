# Roadmap

The **Roadmap** panel is the desktop planning surface for ideas and feature sequencing. Use it before detailed specs or action plans when you need to organize what should be built and when.

Open via: **Plan menu -> Roadmap** or the Panel Selector.

## What you can do

- Capture feature ideas in the ideation view.
- Organize planned features into roadmap phases.
- Move ideas into roadmap items.
- Edit feature and phase details.
- Use roadmap context as the starting point for specs, UI flows, requirement plans, or agent work.
