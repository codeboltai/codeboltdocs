# Action Plans

The **Action Plan** panel shows executable plans made of tasks and step groups. Agents can create action plans automatically, and users can inspect or edit them from the desktop.

Open via: **Plan menu -> Action Plan**, action-plan widgets in chat, or the Panel Selector.

## What you can do

- Create a new action plan with a name and description.
- Open an action plan detail panel.
- Add tasks to a plan.
- Organize work into parallel, loop, if, and wait-until groups.
- Switch between detail, flow, and timeline-style views.
- Open thread context from plan items when a task has agent conversation state.
