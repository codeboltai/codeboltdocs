# Application Planning Features

Application Planning Features are the desktop panels used to turn product intent into structured implementation context.

Open these panels from the footer **Plan** menu, file-tree planning files, chat planning widgets, or the Panel Selector.

## Feature map

| Feature | Use it for |
|---|---|
| [Tasks](./01_tasks.md) | Track planning work items and task details created by users, agents, plans, and jobs. |
| [Roadmap](./02_roadmap.md) | Capture ideas, organize roadmap phases, and move ideas into planned feature work. |
| [Specs](./03_specs.md) | Write and edit `.specs` files that define requirements, acceptance criteria, and implementation notes. |
| [UI Flow](./04_ui-flow.md) | Open `.canvas` UI flow files and keep visual workflow context beside specs and plans. |
| [Action Plans](./05_action-plans.md) | Break implementation into executable task steps, groups, flow views, and timelines. |
| [Requirement Plan](./06_requirement-plan.md) | Combine specs, UI flows, action plans, and notes into one planning document. |
| [Project Structure](./07_project-structure.md) | Inspect the modeled application structure before proposing or reviewing structural changes. |
| [Codemap](./08_codemap.md) | Read generated `.codemap` files that map code paths, traces, and file references. |
