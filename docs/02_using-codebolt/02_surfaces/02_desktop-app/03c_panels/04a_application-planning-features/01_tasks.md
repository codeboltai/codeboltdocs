# Tasks

The **Tasks** panel is the desktop task-tracking surface for planning and execution work. Use it to inspect work items created by agents, plans, jobs, or user workflows.

Open via: **Plan menu -> Tasks** or the Panel Selector.

## What you can do

- View task lists and task details.
- Inspect task issue detail when a task needs attention.
- Track task status as agents work through a plan or job.
- Open task-related environment detail when a task is tied to an execution context.

## Related panels

- [Action Plans](./05_action-plans.md) break work into ordered task steps.
- [Requirement Plan](./06_requirement-plan.md) can package tasks with specs and UI flows.
- [Jobs](../04b_agent-management-features/06_jobs.md) distribute work across coordinating agents.
- [Environments](../04d_agent-orchestrations/03_environments.md) show where task work runs.
