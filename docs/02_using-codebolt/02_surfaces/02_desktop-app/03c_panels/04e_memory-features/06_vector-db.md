# Vector DB

Vector DB stores semantically searchable data for retrieval. Use it when you need to inspect whether project content has been embedded and can be found by similarity search.

Open via: **Context menu -> Vector DB**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Inspect vector collections or records.
- Confirm that retrieval data exists for a project.
- Debug missing semantic search results.
- Use Vector DB alongside Knowledge and Context Assembly.
