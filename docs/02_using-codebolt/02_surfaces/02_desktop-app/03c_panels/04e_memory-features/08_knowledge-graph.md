# Knowledge Graph

Knowledge Graph gives a graph-oriented view of project knowledge. Use it when relationships between entities matter more than a flat document or vector result.

Open via: **Context menu -> Knowledge Graph**, the panel-header **+** menu, KG result widgets in chat, or the Panel Selector.

## What you can do

- Inspect entities and related records.
- Explore graph relationships around a project concept.
- Open graph context from chat result widgets.
- Use graph results as supporting context for agent work.
