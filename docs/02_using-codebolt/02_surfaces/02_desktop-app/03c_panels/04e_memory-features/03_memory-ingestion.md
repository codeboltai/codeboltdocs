# Memory Ingestion

Memory Ingestion manages the pipelines that load project information into memory systems. Use it when project files, events, or structured records should become available to retrieval and context assembly.

Open via: **Context menu -> Memory Ingestion**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Inspect ingestion pipelines and runs.
- Bring project data into memory-backed retrieval.
- Debug ingestion failures before relying on memory in agent prompts.
- Pair ingestion with Persistent Memory and Context Assembly.
