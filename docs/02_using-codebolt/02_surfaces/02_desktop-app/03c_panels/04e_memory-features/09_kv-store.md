# KV Store

KV Store is the key-value storage surface for project and agent workflows. Use it when a workflow needs simple persisted values rather than document or graph retrieval.

Open via: **Context menu -> KV Store**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Inspect key-value records.
- Use stored values as workflow state.
- Debug agent or plugin behavior that depends on persisted keys.
- Keep lightweight project state separate from document memory.
