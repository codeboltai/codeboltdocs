# Calendar

Open **Tools → Calendar** or search for **Calendar** in the panel selector. Add an event with a time and description to record when work should happen. Calendar also shows occurrences of enabled scheduled automations when their calendar display option is enabled.

## Calendar views

The desktop calendar includes month, week, day, hour, and schedule-style views.
