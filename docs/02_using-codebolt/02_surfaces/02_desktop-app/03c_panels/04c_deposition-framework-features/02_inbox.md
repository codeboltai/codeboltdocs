# Inbox

The **Inbox** panel collects agent messages that need human attention. In deposition workflows, an inbox message is a durable handoff that explains what happened and what needs pickup.

Open via: **Tools menu -> Inbox** or the Panel Selector.

## What gets deposited

- Blocked-task messages.
- Missing credential or approval requests.
- Completion notices.
- Critical failure reports.
- Thread, runtime, project, or file references.

## Pickup workflow

1. Open the Inbox.
2. Filter or select the relevant thread.
3. Read the message and attached references.
4. Continue in the related chat, job, environment, or review request.
