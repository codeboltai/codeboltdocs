# Kanban Board

The Kanban Board is a task-management view for agent work. It gives task threads and steps a board-style layout so you can see what is waiting, active, blocked, or complete.

Open via: **Panel Selector -> Kanban Board**, task thread actions that open a task in Kanban, or the panel-header **+** menu when available.

## What you can do

- Review task progress as cards grouped by status.
- Open task details from a board item.
- Move between task planning and task execution context.
- Use it alongside Tasks, Action Plans, Running Agents, and Thread Panel when managing multi-step work.
