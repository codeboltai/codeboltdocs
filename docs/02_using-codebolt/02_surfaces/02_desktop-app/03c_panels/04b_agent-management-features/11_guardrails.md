# Guardrails

Guardrails control how agent actions are checked before they execute. They help prevent risky tool calls, enforce project rules, and add review points around sensitive work.

Open via: **System menu -> Guardrails**, the panel-header **+** menu, or the Panel Selector.

## What you can do

- Inspect guardrail configuration for the current project.
- Understand why an action was allowed, blocked, or routed for review.
- Coordinate guardrails with agent evaluations and routing behavior.
- Use guardrails before enabling automated or background workflows.
