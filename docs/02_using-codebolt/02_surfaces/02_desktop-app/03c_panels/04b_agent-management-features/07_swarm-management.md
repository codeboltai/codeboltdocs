# Swarm Management

The **Swarm Management** panel manages groups of agents working toward a shared goal.

Open via: **Execution menu -> Swarm Management** or the Panel Selector.

## What you can do

- Create and delete swarms.
- Attach agents to a swarm.
- Manage teams, roles, and role assignments.
- Create and close vacancies.
- Start and stop swarm execution.
- Review spawn and termination requests.
- Inspect activity and configuration tabs.
- Save and restore the swarm layout for the project.

## Backing server features

The desktop panel uses `/swarm/swarms`, `/swarm/swarms/:swarmId/agents`, `/swarm/swarms/:swarmId/teams`, `/swarm/swarms/:swarmId/roles`, `/swarm/swarms/:swarmId/vacancies`, and related spawn, termination, config, status, and layout routes.
