# Thread Coordination

Open **Execution → Thread Coordination** in the desktop app to inspect related threads, navigate to a conversation, or stop an execution. Use it to follow work that a parent agent delegates to subagents.

See [Orchestrators](../../../../07c_agent-coordination/06_orchestrator-management.md) for how agents divide work.
