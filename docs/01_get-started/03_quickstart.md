# Get Started

Codebolt is the same agent runtime no matter how you talk to it — you just pick the **client** that fits how you want to work. Each guide below walks through **installation, sign-in, provider setup, and your first agent run** end to end.

Pick one to get going in about 5–10 minutes:

| Client | Best for | Guide |
|---|---|---|
| **Desktop App** | Daily coding work, multi-panel context, visual diffs, rich chat | [Get Started →](../02_using-codebolt/02_surfaces/02_desktop-app/00_get-started.md) |
| **CLI** | Terminal workflows: interactive CLI interface, command mode, headless server, and one-shot prompts | [Get Started →](../02_using-codebolt/02_surfaces/04_cli/01_cli-interface/00_get-started.md)<br/>[CLI Interface](../02_using-codebolt/02_surfaces/04_cli/01_cli-interface/01_overview.md) · [Command Mode](../02_using-codebolt/02_surfaces/04_cli/02_cli-commands/01_overview.md) · [Headless CLI](../02_using-codebolt/02_surfaces/04_cli/03_cli-headless/01_overview.md) |
| **Cloud** | Browser-based access with no install — managed sandboxes or drive your own machine from anywhere | [Cloud Platform →](./02f_platforms/04_cloud.md) |

> **Heads up:** the desktop app is the most common starting point. If you're not sure which to pick, start there. The CLI includes the interactive terminal interface, command mode, and headless modes, and is bundled with the desktop app. **Cloud** is the no-install option if you'd rather work from a browser.

---

## What every guide covers

Whichever client you choose, the Get Started guide will take you through:

1. **Download and install** — the right package for your OS
2. **Sign in** — connect your CodeBolt account
3. **Choose an AI provider** — built-in CodeBolt AI (no key needed) or your own OpenAI / Anthropic / local model
4. **Run your first agent** — open a project and send a real task
5. **Review and roll back** — checkpoints keep every change safe
