# Desktop App

The Codebolt **Desktop App** is the full graphical client. Install it on macOS, Windows, or Linux and you get a docked, multi-panel workspace for daily coding with agents. It is the richest surface: multi-tab chat, visual diffs, `@mentions`, inline editing, and the full panels ecosystem.

> New here? The **[Get Started](../02_surfaces/02_desktop-app/00_get-started.md)** guide walks you through install, sign-in, provider setup, and your first agent run in about 5–10 minutes.

## How to launch

Open **Codebolt.app** (or your OS launcher), then pick **Open Project** → choose any folder. Codebolt indexes it in seconds and opens a chat panel.

## What's desktop-only

Some affordances only exist in the desktop client (see the [Platform Overview](../02_surfaces/01_overview.md) for what varies across clients):

- `@mentions` and panel context pickers
- Ctrl+K inline editing
- Multi-pane visual diffs
- Multi-tab chat
