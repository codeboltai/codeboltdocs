---
title: Web Search Providers
---

Open **System → Settings → Web Search** to configure a search provider and choose which one Codebolt uses by default.

1. Expand the provider you want to use. Fill in the fields it asks for, such as an API key or the URL of your SearXNG instance.
2. Select **Save Provider**. If a plugin provider shows a login button, sign in through that button.
3. Under **Default Web Search**, select your configured provider and enter the default number of results (1–20).
4. Select **Save Default** to apply the provider and result count.

To switch between providers you have already configured, repeat steps 3 and 4.
