---
title: Flags
---

Flags are named tags that agents and plugins can read. Use a flag name recognized by the agent or plugin you’re configuring.

1. Open **System → Settings → Flags**. Select **User** for a personal flag or **Project** for a flag belonging to the open project.
2. Enter the name in **Add a flag** and press **Enter**. It appears under **Available Flags**.
3. Select **Enable** beside the flag. It moves to **Enabled Flags** for the selected scope.

To turn it off, select **Disable** under **Enabled Flags**. You can enable it again from **Available Flags**.
