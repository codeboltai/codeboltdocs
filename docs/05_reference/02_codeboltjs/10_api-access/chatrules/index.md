```text
codebolt.chatrules.getInitialPrompt(selection: ChatRuleSelection, threadId?: string): Promise<ChatRulePrompt>
```

### getFullPrompt

```text
codebolt.chatrules.getFullPrompt(selection: ChatRuleSelection, threadId?: string): Promise<ChatRulePrompt>
```
