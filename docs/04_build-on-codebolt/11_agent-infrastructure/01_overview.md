# Agent Infrastructure

The desktop app starts the server it uses for project work. With the CLI you can also start a standalone runtime, attach a terminal UI, or run a headless prompt.

- [Running the Server](./02_running-the-server.md) covers standalone startup.
- [Application Storage](./03_database.md) identifies the runtime and project data directories.
- [Scaling and Workers](./05_scaling-and-workers.md) covers parallel work and execution environments.
- [Backup and Restore](./07_backup-and-restore.md) covers copying application and project state.
- [Remote Execution](./09_remote-execution.md) introduces remote environments.

For a cloud-managed runtime or a connected local machine, see [Cloud Scaling](../../01_get-started/04_core-concepts/07_cloud-scaling.md).
