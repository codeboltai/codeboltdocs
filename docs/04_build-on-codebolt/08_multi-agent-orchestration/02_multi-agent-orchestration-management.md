# Managing Multi-agent Orchestration

Build orchestration by having a parent agent [delegate work to subagents](../03_agent-extensions/08_subagents.md). Open **Execution → Thread Coordination** in the desktop app to inspect the parent and child threads, drill into a run, or stop an execution.

See [Orchestrators](../../02_using-codebolt/07c_agent-coordination/06_orchestrator-management.md) for the desktop workflow and [Jobs](../../02_using-codebolt/07c_agent-coordination/02_jobs.md) for shared work tracking.
