# Keep agent work in scope

Review long-running work at named checkpoints. You can make those checkpoints part of an agent workflow.

1. Write a task with a specific outcome, files or areas in scope, and acceptance criteria.
2. Capture the plan before execution. When reviewing a milestone, compare the changed files and the reports from the agent with those criteria.
3. If the work has moved outside the plan, record feedback and request changes before merging. Use a separate reviewer when your workflow calls for independent review.

See [Execution Plans](../../02_using-codebolt/02_surfaces/02_desktop-app/03c_panels/04a_application-planning-features/05_action-plans.md) and [Review and Merge](../../02_using-codebolt/07_multi-agent-usage/04_review-and-merge.md) for the product controls.
