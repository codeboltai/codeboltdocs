# Intro to Cloud

Codebolt Cloud extends local agent workflows into hosted and remote environments. Use it when you need managed runtimes, remote execution, shared environments, or cloud-backed collaboration around agent work.

This section covers the builder-facing cloud concepts: how cloud environments fit into agent development, how remote work is organized, and how cloud infrastructure supports larger Codebolt deployments.
